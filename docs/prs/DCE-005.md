## PR and completion protocol

Use leading stable ID `DCE-005: ...`; link this unit and explicit dependencies. Map only real PR numbers into registry/prs.json. Require current-head CI and the checked-in merge preflight before authorized merging. Failed, missing, pending or skipped required checks remain blockers. Human review and independent certification are deferred until the deployed result is ready for the owner; concrete vulnerabilities and failing tests are not waived. Merged source, tested code, deployment and live operational acceptance are separate states.
