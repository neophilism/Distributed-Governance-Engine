Use expand/contract migrations and scoped feature flags. Reconcile old/new records before switching readers. For work without persistent schema changes, record that fact with the final diff. If a release changes authority, eligibility or cryptographic boundaries, add an ADR and a tested migration path.

## PR and completion protocol

Use leading stable ID `DCE-001: ...`; link this unit and explicit dependencies. Map only real PR numbers into registry/prs.json. Require current-head CI and the checked-in merge preflight before authorized merging. Failed, missing, pending or skipped required checks remain blockers. Human review and independent certification are deferred until the deployed result is ready for the owner; concrete vulnerabilities and failing tests are not waived. Merged source, tested code, deployment and live operational acceptance are separate states.
