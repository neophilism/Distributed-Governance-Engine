# Public draft CRDT convergence (partial DCE-008)

This increment pins stable Yjs v13, y-prosemirror v1.3.7 and browser/server WebSocket dependencies in the npm lockfile. It adds createPublicSharedDraft: a bounded **in-memory** Yjs update/merge adapter for collaboration documents that the caller explicitly marks PUBLIC.

- One authorized source seeds the initial ProseMirror legal tree. Other clients must hydrate from that source's update; separately seeding two replicas independently would duplicate initial content.
- Incremental updates use Yjs state vectors; applying duplicate or reordered updates converges. An update is staged in an independent Y.Doc, projected into the legal schema, then committed to the live Y.Doc only after validation. Failed, malformed or oversized updates leave the live document untouched.
- The adapter refuses frozen/public-input/adopted editions and all documents not explicitly classified public. Viewer sessions may receive updates but cannot originate local changes.
- A caller-provided local-update callback is invoked only for accepted local edits. The module does not create a public network endpoint, authenticate users, persist updates, or grant membership.
- The model adapter provides domain snapshots for projection and testing. Yjs binary updates—not exported legal JSON—must remain the synchronization source of truth. Persisting/distributing only JSON loses CRDT concurrency history.

**Not yet complete:** authenticated WSS room admission and per-message revocation checks, durable update/outbox storage, encrypted private envelopes and membership rekeying, ProseMirror live plugin/mount integration, browser multiuser reconnect evidence, CPU/memory bounds under adversarial updates, and production acceptance. This module is intentionally NOT enabled for confidential workspace content or advertised as a deployed realtime editor.

The temporary CI workflow used to generate the reproducible npm lockfile was removed after the package and exact lockfiles were committed. All checks must pass on the final PR head before merging.

## Authenticated public WebSocket transport (additional partial increment)

The public-only HTTPS server now exposes an optional, bounded TLS 1.3 WebSocket endpoint at /ws/public/:workspaceUuid/:documentUuid, configured with strict same-origin and cookie-bound session/CSRF validation. The relay calls the existing document store for authorization at connection and on **every incoming frame**, saves accepted content-changing updates with the existing expected-version and command-ID transaction boundary, and rechecks each receiver before forwarding public updates. Viewers may receive the public CRDT state but cannot write; revoked memberships, frozen sources and invalid origins are refused. WebSocket compression is disabled, updates are bounded to 64 KiB, active room/client counts and pending work are limited, and the service closes rooms on shutdown. Client frame opcodes are 1 = snapshot/update response, 2 = editor update, 3 = state-vector request.

This is **still incomplete DCE-008**: clients currently must speak this small binary transport themselves; a ready-to-use ProseMirror mount/provider UI is not yet wired. The Yjs state lives in memory only, and is not durably retained across server restart, room closure or multiple replicas; only the semantic document snapshots are persisted. An out-of-band HTTP save invalidates room version and forces reconnect. Full CRDT history persistence, compaction, resumed state-vector reconnection, cross-node broadcasts, documented privacy and denial-of-service acceptance, and multiuser browser load tests remain required. This transport **never** handles confidential/private content and does not claim encryption beyond TLS. Do not call this deployed real-time collaboration or production-accepted E2EE.

## Opt-in Quill live editor

The saved public document UI offers an explicit **Join live editing** choice for signed-in workspace members with an editable collaboration draft. It first flushes a pending ordinary public save and reloads the current persisted source, then joins its authenticated same-origin WebSocket room. The live ProseMirror editor uses the stable ySyncPlugin/yUndoPlugin binding so formatting and cursor-based text changes generate binary Yjs increments instead of competing HTTP whole-document writes. Viewers can observe synchronized text; only editor roles can send changes. Exiting live mode reloads the most recently persisted ordinary public version. Disconnect or invalid inbound updates stops editing without silently falling back to a plaintext offline cache.

The web UI explicitly warns that the server has **no durable realtime acknowledgement protocol** and Yjs binary history remains in-memory. Therefore network disconnects or server restarts may lose unacknowledged edits; export working text as a precaution. Realtime text, exports and navigation are still not independently production-accepted. Private documents remain excluded from this UI and server. The live mode is opt-in, not the default, until durable CRDT updates, reconnect and production browser acceptance are completed.
